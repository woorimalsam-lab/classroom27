# 🏫 학급 게시판

학생·학부모가 보는 우리 반 게시판입니다. [우리말샘 핀](https://woorimalsam-lab.github.io/woorimalsam/)(교사용 앱)과 같은 Firebase 프로젝트를 사용합니다.

**주소: https://woorimalsam-lab.github.io/classroom27/**

## 메뉴 구성

| 메뉴 | 내용 | 데이터 출처 |
|---|---|---|
| 📢 공지사항 | 마감 일자·제출 서류 공지 (D-day 자동 표시) | Firestore `classboard_notices` — 교사가 게시판에서 직접 작성 |
| 📋 출결 🔒 | 날짜별 출결 특이사항 (기록 없으면 "전원 출석"), 이름은 가려서 표시 | 우리말샘 핀 → 출결에서 **게시판 공유**를 켜면 우리 반 전용 공간에 자동 발행 |
| 📄 명렬표 🔒 | 제출 항목별 제출 체크, 이름은 가려서 표시 | Firestore 우리 반 전용 공간 — 교사가 게시판에서 직접 관리 |
| 📅 일정 | 학사일정 달력 + 다가오는 일정 D-day | 우리말샘 핀의 `academic-calendar.js`를 실시간으로 불러옴 |
| 🍽️ 급식 | 주간 급식 식단표 (알레르기 정보 포함) | NEIS 교육정보 개방 포털 API (심원고등학교) |
| 💌 익명 우체통 | 학생 → 교사 1:1 비밀 메시지 (완전 익명 가능) | Firestore `classboard_messages` — 교사만 열람 가능 |

## ⚙️ 최초 1회 설정 (필수)

**Firestore 보안 규칙 적용** — 이걸 해야 공지·출결·익명 메시지가 동작합니다.

1. [Firebase 콘솔 → Firestore 규칙](https://console.firebase.google.com/project/woorimalsam-7f454/firestore/rules) 접속 (woorimalsam@gmail.com 로그인)
2. 기존 규칙을 지우고 이 폴더의 **`firestore.rules`** 파일 내용을 통째로 붙여넣기
3. **[게시]** 버튼 클릭

> **2026-10 규칙 변경 — 다시 붙여넣기 필요.** 출결·명렬표를 우리 반 전용 공간으로 옮기면서 규칙이 바뀌었습니다.
> 새 규칙을 게시한 뒤 게시판에 **교사 로그인**을 한 번 하면, 예전 공개 문서(`classboard/attendance·roster·checklists`)가
> 자동으로 새 공간으로 옮겨지고 지워집니다.

## 🔒 우리 반 전용 메뉴 (출결·명렬표)

게시판 주소는 누구나 열 수 있으므로, 학생 이름이 들어가는 출결·명렬표는 **학급 링크를 받은 기기에서만** 보입니다.

- **학급 링크 나눠 주기**: 교사 로그인 → 출결 또는 명렬표 탭의 **🔑 학생용 링크** → 링크 복사 또는 QR을 반에 공유.
  학생은 한 번만 열면 그 기기에서 계속 볼 수 있습니다. 링크 없이 들어오면 잠금 안내만 보입니다.
- **이름 가리기**: 학생이 보는 데이터에는 `김*수` 형태만 저장됩니다. 실명 명단과 제출 비고는 교사 전용 문서에만 있어 학생에게는 보이지 않습니다.
  (설문 결과·엑셀은 교사 화면에서 번호로 실명을 찾아 보여 줍니다.)
- **링크가 학급 밖으로 퍼졌다면**: 🔑 학생용 링크 → **🔄 새 링크로 바꾸기**. 예전 링크는 바로 막히고, 학생들에게 새 링크를 다시 나눠 주면 됩니다.
- 수업 도구(뽑기·모둠·대진표)에서 실명을 쓰려면 교사 로그인 상태여야 합니다. 로그인하지 않은 화면에서는 가린 이름이 쓰입니다.
- 저장 위치: `classboard_class/{학급코드}_attendance·_roster·_checklists`(반 전용, 가린 이름),
  `classboard_teacher/settings·roster·checklist_memos`(교사 전용).

## 👩‍🏫 교사 사용법

- **공지 쓰기**: 게시판 우측 상단 **교사 로그인**(구글) → 공지사항 탭에 **+ 공지 쓰기** 버튼이 나타남
- **출결 공유**: 우리말샘 핀에 구글 로그인 → 출결 탭 → **🌐 게시판 공유** 버튼을 켬 → 이후 출결을 입력할 때마다 자동으로 게시판에 반영 (비고는 공유되지 않음)
- **익명 메시지 확인**: 교사 로그인 상태에서 익명 우체통 탭 → 받은 메시지함 표시

## 🧑‍🎓 학생 사용법

로그인 없이 모든 메뉴 이용 가능. 출결·명렬표는 선생님이 나눠 준 학급 링크(또는 QR)로 한 번 접속하면 보입니다. 익명 우체통에서 선생님께 비밀 메시지를 보낼 수 있고, 보낸 내용은 선생님만 볼 수 있습니다.

## 파일 구성

- `index.html` / `style.css` / `app.js` — 게시판 본체 (정적 사이트, GitHub Pages 배포)
- `bookshelf/` — 우리 반 책장 (10월 활동 책 템플릿). 게시판 메뉴의 📚 **우리 반 책장**에서 열림. 책은 각 브라우저에 저장되고, 💾 내보내기(.json)로 다른 기기에 옮길 수 있음
- `config.js` — Firebase 설정, 교사 이메일, NEIS 학교 코드
- `firestore.rules` — Firebase 콘솔에 붙여넣는 보안 규칙 (배포 파일 아님)

## 참고

- 급식 API는 키 없이 동작합니다. 호출이 많아져 제한에 걸리면 [NEIS 개방 포털](https://open.neis.go.kr)에서 무료 키를 발급받아 `config.js`의 `NEIS.key`에 넣으세요.
- 학사일정이 바뀌면 우리말샘 핀 저장소의 `academic-calendar.js`만 교체하면 게시판에도 자동 반영됩니다.

## 글꼴

**강원교육 글꼴** (강원특별자치도교육청 무료 배포)을 사용합니다.

| 글꼴 | 쓰임 |
|---|---|
| 강원교육모두 Bold | 본문 전체 (잘 보이도록 굵은 쪽을 사용) |
| 강원교육튼튼 | 제목·브랜드·큰 숫자(시계·타이머·점수판·뽑기 결과) |
| 강원교육현옥샘 | 손글씨 포인트(안내 문구, 빈 화면 메시지) |
| 강원교육새음 | 급식 식단 |

- 웹 사용을 위해 원본 TTF를 **WOFF2로 변환하고 글자 수를 줄여(subset)** `fonts/` 에 두었습니다.
- `fonts.css` 와 `fonts/` 는 **자동 생성물**입니다. 직접 고치지 말고 아래 명령으로 다시 만드세요.

  ```bash
  python tools/build-fonts.py
  ```

  본문을 얇게 되돌리려면 `tools/build-fonts.py` 의 `FACES` 에서 `강원교육모두 Bold.ttf` 를 `강원교육모두 Light.ttf` 로 바꾸고 다시 실행하면 됩니다.
- 2단계 로딩: 자주 쓰는 글자(1단계)를 먼저 내려받고, 드문 글자는 화면에 나올 때만(2단계) 내려받습니다.
- 이 글꼴은 비영리·교육 목적으로 사용 중이며, 글꼴 파일 자체를 판매하거나 유료 배포하지 않습니다.
